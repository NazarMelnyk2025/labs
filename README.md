# WEB-лабораторні №3–8

Студент: Мельник Назар, група КН-310.

Репозиторій підготовлено з останніх локально перевірених версій готових робіт. Функціональність лабораторних не змінювалася. Кореневий `index.html` містить навігацію, а проєкти розміщено в `lab3`–`lab8`.

## Запуск

З кореня репозиторію:

```bash
python -m http.server 8000
```

Відкрити `http://127.0.0.1:8000/`.

Для ЛР №8 збірка виконується окремо:

```bash
cd lab8
npm ci
npm run build
npx tsc --noEmit
```

## Git

Локально створено гілки `lab3`–`lab8`; кожна має окремий commit із відповідною роботою та пунктом навігації. Усі гілки злито в `main`. Віддалений `origin` навмисно не задано: створення/вибір GitHub-репозиторію, push та ввімкнення хостингу потребують дозволу власника.

Деталі перевірок містяться у `verification/`, а точний план зовнішніх дій — у `PUBLICATION_PLAN.md`.
