## Компіляція SCSS

У каталозі `lab3` виконайте:

```bash
sass --style=expanded --source-map scss/styles.scss css/styles.css
```

Якщо Sass не встановлено, встановіть його в межах проєкту через npm відповідно до методички або використайте наявний компілятор.

## Локальний запуск

```bash
python -m http.server 8000
```

Відкрити: `http://localhost:8000/`.

Зображення карток завантажуються з офіційного сайту ЛПНУ, тому потребують мережевого доступу.

## Матеріали архіву

- `REPORT.md` — Markdown-звіт.
- `reports/REPORT.docx`, `reports/REPORT.pdf` — готові друковані версії звіту.
- `screenshots/` — оригінальні PNG.
- `logs/` — журнали перевірок Codex.
