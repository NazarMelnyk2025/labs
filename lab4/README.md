# WEB ЛР №4 — «Робота з функціями у JavaScript»

Студент: Мельник Назар, група КН-310. Варіант 2.

## Запуск у браузері

```bash
cd source
python -m http.server 8001
```

Відкрити `http://127.0.0.1:8001/`. Результати завдань виводяться в
консоль браузера.

## Перевірка через Node.js

```bash
cd source
node --check main.js
node main.js
```

## Вміст

- `source/` — готові `index.html` і `main.js`;
- `screenshots/` — перевірені справжні PNG сторінки та результатів;
- `logs/` — фактичні журнали Node.js, алгоритмічних і браузерних перевірок;
- `reports/` — фінальний звіт у Markdown, ODT, DOCX і PDF;
- `VERIFICATION.md` — карта виконання вимог і відомі обмеження.

Пакет не потребує `node_modules`: сторінка використовує лише стандартний
JavaScript, а Node.js потрібен тільки для додаткової перевірки.
