## Запуск

```bash
cd source
python -m http.server 8077
```

Відкрити `http://127.0.0.1:8077/`.

## Вміст

- `source/` — перевірена реалізація ЛР №7;
- `tests/` — Playwright CRUD-сценарій і unit-тест дати;
- `screenshots/` — реальні знімки браузера;
- `logs/` — HTTP, консоль, синтаксична й тестова перевірки;
- `reports/` — звіт у Markdown, DOCX і PDF;
- `VERIFICATION.md` — підсумок аудиту.

Залежності та `node_modules` до архіву не включено. Тестовий запис створюється з унікальним заголовком і видаляється наприкінці сценарію.


## Автоматизовані тести (переносимі шляхи)

Із кореня архіву (`WEB_LR07/`):

```bash
node --check source/js/index.js
node tests/date_unit.js
```

Для необов'язкового повторного запуску CRUD через реальний MockAPI потрібно встановити Playwright і браузер Chromium у доступному Node.js-середовищі:

```bash
npm install --no-save playwright
npx playwright install chromium
python -m http.server 8077 -d source
```

В іншому терміналі, з кореня `WEB_LR07/`:

```bash
node tests/crud_playwright.js
```

Увага: CRUD-тест звертається до **живого зовнішнього сервісу**, створює, змінює та видаляє власний тимчасовий запис. Не запускайте його повторно без потреби. За помилки перевірте, чи не залишився тестовий запис із префіксом `LR07_AUDIT_`. Результати оригінального запуску Codex збережені у `logs/`.

## Повторне формування звіту

Скрипт `tests/build_report.py` потребує `python-docx` та `Pillow`. У DOCX скриншоти **лише кадровані по порожніх краях** для читабельності; вихідні PNG у `screenshots/` не змінено. Після зміни DOCX перевірте PDF-експорт візуально.
